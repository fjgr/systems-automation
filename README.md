# ⚙️ Systems & Automation

Repositorio dedicado a herramientas, scripts y automatizaciones relacionadas con la administración de sistemas y la gestión de infraestructuras.

Forma parte de **FJGR Labs** y recopila soluciones orientadas a simplificar tareas operativas, automatizar procesos y mejorar la administración de entornos Linux.

---

## 🛠️ Tecnologías

* Linux
* Docker
* Bash
* Python
* Git

---

## 📂 Contenido

### 🐧 Linux

Configuraciones, documentación y herramientas para sistemas Linux.

### 🐳 Docker

Stacks, contenedores y entornos reproducibles.

### ⚡ Automatización

Scripts y procesos para automatizar tareas repetitivas.

### 📜 Utilidades

Herramientas desarrolladas para facilitar la gestión diaria de sistemas.

---

## 🚀 Objetivo

Crear y documentar soluciones que permitan administrar sistemas de forma más eficiente, automatizada y mantenible.
